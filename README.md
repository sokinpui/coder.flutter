# coder.flutter

Cross-platform Flutter client for the [Coder](https://github.com/sokinpui/coder) AI code editor ecosystem.

## Prerequisites

Start the Coder daemon with WebSocket support:

```bash
coder --ws
```

## Ecosystem

- **[coder](https://github.com/sokinpui/coder)**: Core AI code editor engine and CLI/TUI suite.
- **[coder.nvim](https://github.com/sokinpui/coder.nvim)**: Neovim plugin for seamless terminal & IPC integration.
- **coder.flutter**: Modern GUI client for macOS, Linux, Windows, Android, and Web.
```

## Run

```bash
flutter run -d macos # or chrome, android
```
